# Haze Messenger — Техническая документация

## Обзор

**Haze** — мессенджер в экосистеме SSA (Single Sign-On Authentication), построенный по микросервисной архитектуре с фокусом на премиум-функционал, глубокую настройку и современный Liquid Glass дизайн.

## SSA Экосистема

Мессенджер интегрирован в экосистему SSA:

- **SSO-авторизация**: Единый вход через SSA OAuth2/OIDC
- **Единый профиль**: Аватар, имя, статус — синхронизируются через SSA
- **Кроссплатформенность**: Сессия работает на всех устройствах через SSA
- **Безопасность**: 2FA через SSA, биометрия
- **Единые настройки**: Темы, уведомления — синхронизируются через SSA

## Юзернеймы и бейджи

### Юзернеймы
- Формат: `@username` (латиница, цифры, подчёркивание)
- Уникальность: глобальная проверка уникальности
- Кликабельность: клик → переход в профиль/чат
- Поиск: поиск пользователей по @username
- Ссылки: `https://haze.app/u/username` (или `haze://u/username`)
- Смена: ограничение 1 раз в 30 дней

### Бейджи (иконки рядом с именем)
| Бейдж | Описание | Кто назначает |
|-------|----------|---------------|
| 👑 Owner | Владелец мессенджера | Система (1 аккаунт) |
| ⚙️ Developer | Разработчик платформы | Owner |
| ⭐ Premium | Премиум-подписка | Система (оплата) |
| 🤖 Bot | Автоматизированный аккаунт | Система |
| 🛡️ Admin | Администратор | Owner/Developer |
| ✅ Verified | Верифицированный аккаунт | Owner/Developer |

### Хранение
- Таблица `user_badges`: user_id, badge_type, assigned_by, assigned_at
- Бейджи отображаются в: профиле, списке участников, сообщениях, поиске
- API: GET /user/{id}/badges, POST /user/{id}/badge (только owner/admin)

## Админ-панель

### Доступ
- URL: `https://haze.app/admin` или `/admin` в приложении
- Доступ: только для owner и developer
- Авторизация: через SSA + проверка роли

### Разделы

#### 1. Дашборд
- Количество пользователей (всего, онлайн, новых за день/неделю/месяц)
- Количество чатов, сообщений, звонков
- Активные premium-подписки
- Системные метрики (CPU, RAM, латентность API)

#### 2. Пользователи
- Таблица пользователей с поиском и фильтрами
- Просмотр профиля: username, email, дата регистрации, последний вход
- Действия: заблокировать, назначить роль, сбросить premium
- Массовые действия: бан, удаление, экспорт

#### 3. Чаты и сообщения
- Список чатов с фильтрами (личные, группы, каналы)
- Просмотр сообщений (модерация)
- Удаление сообщений/чатов
- Статистика по чатам

#### 4. Боты
- Список зарегистрированных ботов
- Просмотр: владелец, команды, вебхук, статистика
- Блокировка ботов

#### 5. Premium
- Тарифные планы (CRUD)
- Активные подписки
- История платежей
- Управление лимитами

#### 6. Бейджи и роли
- Назначение бейджей пользователям
- Управление ролями (owner, developer, admin, moderator)
- История назначений

#### 7. Настройки платформы
- Регистрация: включена/выключена
- Лимиты: максимальный размер файла, rate limits
-aintenance mode
- Конфигурация SSA

#### 8. Логи и аудит
- Логи действий пользователей (модерация)
- Аудит-лог действий администраторов
- Экспорт логов

### API админки
- GET /admin/dashboard — статистика
- GET /admin/users — список пользователей
- PUT /admin/user/{id}/role — изменение роли
- POST /admin/user/{id}/badge — назначение бейджа
- DELETE /admin/user/{id}/badge — снятие бейджа
- POST /admin/user/{id}/ban — бан
- GET /admin/chats — список чатов
- GET /admin/bots — список ботов
- GET /admin/premium — статистика premium
- GET /admin/logs — логи

### Профиль
- Аватар, имя, username, био
- Номер телефона, email
- Статус (текст + эмодзи)
- Дата рождения, местоположение

### Конфиденциальность
- Кто видит онлайн-статус
- Кто видит время последнего входа
- Кто может писать первым
- Блокировка/ограничения
- Двухфакторная аутентификация

### Уведомления
- Push-уведомления (вкл/выкл по типам)
- Звуки уведомлений (выбор звука)
- Вибрация
- Уведомления в чатах (тихий режим)
- Уведомления от ботов

### Оформление
- Светлая/тёмная тема
- Цветовые акценты
- Обои для главного экрана
- Обои для каждого чата
- Размер шрифта
- Splash-экран
- Анимации

### Чаты
- Размер сообщений
- Группировка сообщений по времени
- Предпросмотр ссылок
- Автозагрузка медиа
- Сохранение в галерею

### Данные
- Экспорт истории
- Очистка кэша
- Управление памятью

## Docker-архитектура

```yaml
# docker-compose.yml (упрощённо)
services:
  # API Gateway
  gateway:
    image: haze/gateway:latest
    ports: ["443:443"]
    depends_on: [auth, chat, media, call]

  # Auth Service
  auth:
    image: haze/auth:latest
    environment:
      - DB_URL=postgres://...
      - REDIS_URL=redis://...
      - SSA_CLIENT_ID=...
      - SSA_CLIENT_SECRET=...

  # Chat Service
  chat:
    image: haze/chat:latest
    environment:
      - DB_URL=postgres://...
      - REDIS_URL=redis://...
      - NATS_URL=nats://...

  # Media Service
  media:
    image: haze/media:latest
    volumes: ["./media:/data"]
    environment:
      - MINIO_ENDPOINT=minio:9000

  # Call Service (WebRTC)
  call:
    image: haze/call:latest
    environment:
      - STUN_URL=stun:stun.l.google.com:19302
      - TURN_URL=...

  # Bot Service
  bot:
    image: haze/bot:latest
    environment:
      - DB_URL=postgres://...

  # Notification Service
  notification:
    image: haze/notification:latest
    environment:
      - REDIS_URL=redis://...

  # Search Service
  search:
    image: haze/search:latest
    environment:
      - MEILI_URL=http://meilisearch:7700

  # Premium Service
  premium:
    image: haze/premium:latest
    environment:
      - DB_URL=postgres://...

  # Базы данных
  postgres:
    image: postgres:16-alpine
    volumes: ["pgdata:/var/lib/postgresql/data"]

  redis:
    image: redis:7-alpine

  minio:
    image: minio/minio
    command: server /data

  nats:
    image: nats:2-alpine

  meilisearch:
    image: getmeili/meilisearch:latest

volumes:
  pgdata:
```
